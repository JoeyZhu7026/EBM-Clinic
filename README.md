# EBM-Clinic 指南核查助手

基于临床指南的智能合规核查工具：将指南文本自动转化为结构化筛查规则，再根据患者信息逐条匹配，输出可追溯的核查结论。

当前 Demo 以《我国糖尿病视网膜病变临床诊疗指南（2022 年）》筛查章节为例，架构可扩展至任意临床指南。

> **声明**：本工具仅供技术演示与学习，输出不构成医疗建议，请勿用于临床决策。

## 功能特性

- **规则自动提取** — 粘贴指南原文，由 LLM 提取结构化筛查规则（患者条件 + 建议内容），保留原文溯源。
- **变量词典生成** — 自动统计规则涉及的变量、取值类型与同义词，生成标准化词典。
- **规则一致性校验** — 字段覆盖率、数值一致性、运算符一致性三重检查。
- **患者核查** — 输入患者信息（自由文本），逐条判定命中 / 未命中 / 不适用 / 无法判定，并给出判定依据。
- **结果导出** — 规则与词典打包下载，便于存档与二次分析。

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/<your-username>/EBM-Clinic.git
cd EBM-Clinic
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

在项目根目录创建 `.env` 文件，填入你的 LLM API 配置：

```env
QWEN_API_KEY=your-api-key
QWEN_API_BASE=your-api-base
DR_EBM_MODEL=qwen-plus
```

### 4. 启动应用

```bash
streamlit run app/streamlit_app.py
```

浏览器会自动打开 `http://localhost:8501`。

## 使用流程

### 规则库工作台

1. 在左侧「源文本」区域粘贴指南原文，点击 **保存源文本**。
2. 点击 **提取规则**，等待 LLM 逐段处理（通常需要几分钟）。
3. 切换视图查看结果：
   - **规则视图** — 查看提取出的结构化规则及其条件。
   - **变量视图** — 查看变量词典与取值统计。
   - **校验报告** — 查看规则一致性检查结果。
4. 点击 **导出结果** 打包下载全部产物。

### 患者核查

1. 切换到 **患者核查** 页签。
2. 输入患者信息（自由文本或结构化 JSON），或点击「加载示例」快速体验。
3. 点击 **开始分析**，查看每条规则的核查结果：
   - ✅ **命中** — 该筛查建议适用于当前患者。
   - ❓ **无法判定** — 患者信息不足。
   - 🚫 **不适用** — 与当前患者无关。
   - ❌ **未命中** — 条件不满足。
4. 展开任意结果可查看详细判定过程与原文出处。

## 常见问题

**为什么每次启动时规则是空的？**

Demo 版每次启动清空工作台产物，需手动点击「提取规则」「变量视图」等按钮重新生成，确保每次状态干净可控。

**提取规则需要多长时间？**

取决于指南文本长度和 LLM 响应速度，通常需要 2–5 分钟，请耐心等待进度条完成。

**如何更换为其他指南？**

在「源文本」区域粘贴新的指南文本，重新执行提取流程即可。当前架构针对筛查类规则设计，后续版本将支持更多指南类型。
