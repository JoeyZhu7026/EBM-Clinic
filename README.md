# EBM-Clinic 指南核查助手

基于临床指南的智能合规核查工具：将指南文本自动转化为结构化筛查规则，再根据患者信息逐条匹配，输出可追溯的核查结论。

当前 Demo 以《我国糖尿病视网膜病变临床诊疗指南（2022 年）》筛查章节为例，架构可扩展至任意临床指南。

> **声明**：本工具仅供技术演示与学习，输出不构成医疗建议，请勿用于临床决策。

## 功能特性

- **规则自动提取** — 粘贴指南原文，由 LLM 提取结构化筛查规则（患者条件 + 建议内容），保留原文溯源。
- **图形化规则编辑器** — 可视化编辑提取的规则：支持规则类型分组、规则条折叠展开、条件条嵌套、逻辑框（AND/OR）递归组合；提供上移/下移/重归类/删除等操作，保存时自动校验并归一化。
- **变量词典生成** — 自动统计规则涉及的变量、取值类型（numeric/enum）与同义词，生成标准化词典；支持类型兼容性检查（范围运算符 vs 等值运算符），发现错误时拦截后续流程。
- **规则一致性校验** — 字段覆盖率、数值一致性、运算符一致性三重检查，生成校验报告。
- **流程闸门** — 强制顺序工作流：提取规则 → 统计变量 → 校验规则 → 导出规则，每步完成后自动刷新侧边栏状态，未完成的步骤无法跳过。
- **患者核查** — 输入患者信息（自由文本），逐条判定命中 / 未命中 / 不适用 / 无法判定，并给出判定依据。
- **结果导出** — 规则与词典打包下载，导出后生成临时下载按钮，点击其他操作自动消失。

## 架构设计

系统采用四层流水线架构，各层职责清晰：

- **A 层（规则提取与编辑）** — 从指南文本提取结构化规则，提供图形化编辑器，生成变量词典并执行一致性校验。
- **B 层（患者变量解析）** — 从患者自由文本中提取结构化变量值，支持同义词识别与类型推断。
- **C 层（规则匹配引擎）** — 逐条匹配患者变量与规则条件，输出命中/未命中/不适用/无法判定四种结论。
- **D 层（报告生成）** — 汇总匹配结果，生成可追溯的核查报告，包含判定依据与原文出处。

数据流：源文本 → A 层提取规则 → B 层解析患者 → C 层匹配 → D 层生成报告。

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/JoeyZhu7026/EBM-Clinic.git
cd EBM-Clinic
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

在项目根目录创建 `.env` 文件，填入你的 LLM API 配置：

```env
QWEN_API_KEY=your-api-key
QWEN_API_BASE=your-api-base
DR_EBM_MODEL=qwen-plus
```

### 4. 启动应用

```bash
streamlit run app/streamlit_app.py
```

浏览器会自动打开 `http://localhost:8501`。

## 使用流程

### 规则库工作台

应用采用**流程闸门**机制，侧边栏实时显示各步骤完成状态（✅/❌），必须按顺序完成。

1. **保存源文本** — 在左侧「源文本」区域粘贴指南原文，点击 **保存源文本**。
2. **提取规则** — 点击 **提取规则**，等待 LLM 逐段处理（通常需要几分钟）。完成后自动切换到图形化规则编辑器视图。
3. **编辑规则**（可选） — 在图形化编辑器中调整规则：
   - 折叠/展开规则类型和单条规则
   - 编辑规则条件、逻辑关系（AND/OR）
   - 上移/下移/重归类/删除规则条
   - 点击 **保存规则** 保存修改（自动清空后续步骤产物）
4. **统计变量** — 点击 **统计变量** 生成变量词典，自动推断类型（numeric/enum）并检查兼容性。
5. **校验规则** — 点击 **校验规则** 执行三重一致性检查，查看校验报告。
6. **导出规则** — 点击 **导出规则** 打包下载全部产物，出现临时下载按钮。

### 患者核查

1. 切换到 **患者核查** 页签（需先完成导出规则）。
2. 输入患者信息（自由文本或结构化 JSON），或点击「加载示例」快速体验。
3. 点击 **开始分析**，查看每条规则的核查结果：
   - ✅ **命中** — 该筛查建议适用于当前患者。
   - ❓ **无法判定** — 患者信息不足。
   - 🚫 **不适用** — 与当前患者无关。
   - ❌ **未命中** — 条件不满足。
4. 展开任意结果可查看详细判定过程与原文出处。

## 常见问题

**如何更换为其他指南？**

在「源文本」区域粘贴新的指南文本，重新执行提取流程即可。当前架构针对筛查类规则设计，后续版本将支持更多指南类型。

**侧边栏状态显示 ❌ 怎么办？**

按顺序完成各步骤：提取规则 → 统计变量 → 校验规则 → 导出规则。每步完成后状态自动刷新为 ✅。

**保存规则后为什么后续步骤的状态变成 ❌？**

保存规则时自动清空 output/ 目录，避免旧规则被患者核查使用。需重新执行统计变量、校验规则、导出规则。
